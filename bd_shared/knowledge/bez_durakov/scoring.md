# Подсчёт очков

Формулы подсчёта очков по раундам в терминах таблиц и полей базы данных, а также поля представления `team_game_scores`. Сводки игр, данные команд и агрегаты выдаёт `GameDataService`.

## Итог игры

- Итог команды в игре равен `vybor.points + chisla.total_sum + pref.total_sum + pairs.points + razobl.total_sum + auction.total_sum + mot.total_sum`.
- Представление `team_game_scores` (ORM-класс `TeamGameScore`) содержит на каждую пару `(game_id, team_id)` поля `game_date`, `team_name`, очки по раундам `vybor_points`, `chisla_points`, `pref_points`, `pairs_points`, `razobl_points`, `auction_points`, `mot_points` и итог `total_points`. Каждое поле `*_points` равно `points` или `total_sum` соответствующей таблицы раунда.
- Победитель игры определяется по наибольшему `total_points` среди команд с одним `game_id`. Отдельного поля «победитель» в схеме нет.
- Очки «к финалу» перед Моментом истины равны `total_points - mot_points`.

## Выбор и Пары

- В `vybor` и `pairs` есть единственное поле `points`, это итог раунда, введённый ведущим.

## Числа

- В `chisla` поля `task_1`..`task_5` содержат очки за каждый из пяти вопросов, `total_sum` равен их сумме.

## Преферанс

- В `pref` поля `task_1`..`task_7` содержат 1 за верный ответ и 0 за неверный.
- `goal` содержит заказ команды, число от 4 до 7. Если заказ не назван, используется 4.
- `points` равно числу верных ответов, умноженному на 100.
- `bonus` начисляется, если верных ответов не меньше `goal`. При заказе 4 бонус равен 500, при 5 равен 1000, при 6 равен 2000, при 7 равен 4000. Если заказ не выполнен, бонус равен 0.
- `penalty` начисляется, если верных ответов меньше `goal`, и равен разности между заказом и числом верных ответов, умноженной на 250. Если заказ выполнен, штраф равен 0.
- `total_sum` равен `points + bonus - penalty`.

## Разоблачение

- В `razobl` поля `task_1`..`task_4` содержат очки за каждое из четырёх заданий, `total_sum` равен их сумме.

## Аукцион

- В `auction` для каждой из четырёх тем есть три поля с суффиксами `_bid`, `_points` и `_rate`.
- `task_N_bid` содержит ставку команды на тему N отрицательным числом. Минимальная ставка равна минус 100.
- `task_N_rate` содержит коэффициент команды на тему N. Возможные значения таковы: 2.5, 2.0, 1.5 и 1.0. Коэффициенты распределяются по величине ставки. Чем больше ставка по модулю, тем выше место. При равных ставках выше ставится команда с меньшей суммой очков на момент темы (учитываются очки всех предыдущих раундов и уже сыгранных тем аукциона). Если команды совпадают и по ставке, и по очкам, они получают среднее из коэффициентов, приходящихся на их места.
- Количество коэффициентов зависит от числа команд. При девяти командах и меньше один коэффициент 2.5, один 2.0 и один 1.5. При десяти командах и больше один 2.5, два 2.0 и два 1.5. Остальные команды получают 1.0.
- `task_N_points` содержит результат по теме уже с учётом коэффициента. Базовые очки за вопросы темы до умножения на коэффициент лежат в диапазоне от 0 до 1500 с шагом 100, поэтому `task_N_points / task_N_rate` всегда попадает в этот диапазон.
- `total_sum` равен сумме всех восьми полей `_bid` и `_points`.

## Момент Истины

- В `mot` поля `task_1`..`task_3` содержат результат по каждому из трёх вопросов со знаком. Модуль значения равен ставке команды на вопрос, знак показывает, верным ли был ответ.
- Сумма модулей `task_1`, `task_2` и `task_3` равна очкам команды к финалу, то есть `total_points - mot_points` из `team_game_scores`.
- `total_sum` равен `task_1 + task_2 + task_3`.

## Сервис данных

- `GameDataService` предоставляет `get_all_games_summary`, `get_game_by_id`, `get_games_by_date_range`, `get_team_game_scores`, `get_all_teams`, `get_team_statistics`, `get_team_wins` и `get_top_teams`.
