## 🏗️ Архитектура

### Компоненты

1. **Frontend (Streamlit)** - Веб-интерфейс
   - Два представления: Чат и Отчёт
   - Взаимодействие через REST API
   - Визуализация данных

2. **Backend (FastAPI)** - REST API сервер
   - Обработка запросов
   - Управление сессиями
   - Координация агентов

3. **Agent System (AutoGen)** - Интеллектуальные агенты
   - DataCoder - генерация запросов
   - DataAnalyst - анализ результатов
   - Fallback режим без OpenAI

4. **Service Layer** - Бизнес-логика
   - Использует ТОЛЬКО существующие методы из db.py
   - Абстракция над базой данных
   - Обработка данных с Pandas

5. **Database Layer** - Существующие db.py и db_helpers.py
   - SQLAlchemy ORM
   - MySQL база данных

### Принципы

✅ **Сервис-ориентированная архитектура (SOA)**
✅ **Разделение ответственности**
✅ **Слоистая архитектура**
✅ **Использование только существующих методов БД**

## 📊 Используемые методы из db.py

## 📈 Расширение функциональности

### Добавление нового типа отчёта

1. Добавить метод в `GameDataService`:
```python
def get_new_report_type(self, params):
    # Использовать существующие методы db.py
    return self.db.some_existing_method(params)
```

2. Обновить `_interpret_request` в `ReportAgentSystem`:
```python
elif "новый тип" in message_lower:
    return {
        "method": "get_new_report_type",
        "params": {...}
    }
```

3. Опционально добавить endpoint в API
