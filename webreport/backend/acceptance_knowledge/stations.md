# Станции

Таблица `station_readings` хранит показания станций: по одной записи на станцию и день.

## Поля

Каждая запись содержит `reading_id`, название станции `station`, день измерения `reading_day` в формате ISO и целочисленное значение `reading_value`. Сумма значений по одной станции возвращается инструментом `station_total`.
