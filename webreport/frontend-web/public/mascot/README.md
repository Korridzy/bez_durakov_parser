# Shovel assistant concept

`shovel-concept.png` was generated with the built-in ImageGen tool on 2026-09-13. It is the visual reference for the procedural Three.js character and the static fallback when WebGL is unavailable. The live character, grass and flag are meshes. `island.png` is a painted backdrop with a transparent 3D shadow receiver; `mouths.png` is a 4×4 transparent decal atlas. The logo now uses separate shovel and sparkle sprites, documented with their layout and prompts in [the brand notes](../brand/README.md). The other generation prompts are in [refresh-prompts.md](refresh-prompts.md).

## Generation prompt

Use case: stylized-concept. Asset type: character concept and transparent fallback image for an interactive 3D web assistant. Create ONE charming original anthropomorphic garden spade mascot with the warm mischievous desktop-assistant personality of Microsoft Word's Clippy, but unmistakably a SHOVEL, not a paperclip and not a person. Its body is a LARGE broad rounded silver-metal spade blade, gently curved and thick with smooth beveled edges and a softly pointed bottom. Two BIG protruding white oval cartoon eyes with dark plum pupils sit on the upper front of the blade, thick dark expressive curved eyebrows hover above, a small curved smiling mouth sits below. The blade takes about two thirds of the mascot height. A VERY SHORT honey-colored wooden shaft emerges ABOVE the blade, with a chunky horizontal T-handle at its top and soft coral end grips. No arms, legs, hair, hat, clothing or other human body parts. It stands in a friendly slight tilt on a small floating oval island with soft sage-green turf, delicate tufts, a few small lavender crystals, faceted pale-lilac rock underneath, one slim flagpole carrying a flowing coral pennant. Palette fits an elegant warm-white, lavender and sage analytics application with coral accents. Render as a polished actual 3D cartoon collectible, rounded geometry, silky silver metal with broad soft reflections, matte eyes, subtle ambient occlusion, gentle contact shadows, studio key and rim lights, excellent antialiasing. Not a photorealistic tool: appealing, readable silhouette, expressive eyes, refined cozy toy-like materials. Camera: orthographic three-quarter front, slightly above the island, whole character and island visible with comfortable margins, mascot face directed toward viewer. Square composition on a truly transparent background with alpha, NO background plate, NO text, NO labels, NO watermark, NO additional views.
