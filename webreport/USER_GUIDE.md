## Введение

Система веб-отчётов позволяет генерировать аналитические отчёты по данным игр через простой диалог с AI-агентом. Вы описываете что хотите увидеть на естественном языке, а система автоматически создаёт соответствующий отчёт.

### Основные возможности

- 💬 **Диалог с AI**: Описывайте требования к отчёту на русском языке
- 📊 **Визуализация**: Таблицы, графики, метрики
- 📥 **Экспорт**: Сохранение отчётов в CSV
- 🔄 **История**: Сохранение и просмотр истории диалогов
- 🎯 **Гибкость**: Различные типы запросов и отчётов

## Начало работы

### Запуск системы

**С Docker (единственный способ):**
```bash
cd webreport
make start
# ИЛИ
docker-compose up -d
```

**Остановка:**
```bash
make stop
# ИЛИ
docker-compose down
```

**Просмотр логов:**
```bash
make logs
# ИЛИ
docker-compose logs -f
```

### Доступ к системе

После запуска откройте в браузере:
- **Приложение**: http://localhost:28501
- **API документация**: http://localhost:28000/docs
- **Health check**: http://localhost:28000/health

## Работа с чатом

### Ввод требований

1. Выберите **💬 Чат** в боковой панели
2. Введите ваш запрос в текстовое поле
3. Нажмите кнопку **Отправить**
4. Дождитесь генерации отчёта

### Формулировка запросов

Система понимает естественный язык. Примеры:

**Простые запросы:**
- "покажи все игры"
- "список всех команд"
- "покажи очки команд"

**Запросы с фильтрацией:**
- "топ 10 команд по очкам"
- "статистика команды Название"
- "игры за последний месяц"

**Аналитические запросы:**
- "какая команда лучше всего играет в преф?"
- "средние очки команд по категориям"
- "сравни две команды"

### История диалога

В чате отображаются:
- 👤 **Ваши сообщения** (голубой фон)
- 🤖 **Ответы ассистента** (серый фон)
- ⏰ Временные метки
- ✅ Статус выполнения запроса

## Просмотр отчётов

### Переключение на отчёт

1. После генерации отчёта появится сообщение: "✅ Отчёт сгенерирован!"
2. Переключитесь на **📊 Отчёт** в боковой панели
3. Отчёт отобразится с данными и визуализацией

### Элементы отчёта

**Метрики (если доступны):**
- Всего записей
- Средние значения
- Количество уникальных элементов

**Таблица данных:**
- Полные данные в табличном виде
- Сортировка по столбцам
- Прокрутка для больших наборов данных

**Визуализация:**
- Графики для числовых данных
- Выбор колонки для визуализации
- Интерактивные элементы

**Экспорт:**
- Кнопка **📥 Скачать CSV**
- Файл сохраняется с временной меткой
- Формат: `report_YYYYMMDD_HHMMSS.csv`

### Обновление отчёта

Чтобы сгенерировать новый отчёт:
1. Вернитесь в **💬 Чат**
2. Введите новые требования
3. Отчёт обновится автоматически

## Часто задаваемые вопросы

### Общие вопросы

**Q: Система не понимает мой запрос. Что делать?**

A: Попробуйте:
- Переформулировать запрос проще
- Использовать ключевые слова: "игры", "команды", "очки", "статистика"
- Посмотреть примеры выше

**Q: Как очистить историю диалога?**

A: Нажмите кнопку **🗑️ Очистить чат** в боковой панели

**Q: Можно ли экспортировать отчёт?**

A: Да, используйте кнопку **📥 Скачать CSV** в представлении отчёта

**Q: Система работает без OpenAI API?**

A: Да, в fallback режиме. Некоторые сложные запросы могут работать упрощённо.

### Технические вопросы

**Q: Backend не запускается**

A: Проверьте:
1. Docker контейнеры запущены: `docker-compose ps`
2. Логи контейнера: `make logs` или `docker-compose logs backend`
3. База данных доступна на хосте через host.docker.internal:3306
4. Файл bd_shared/config.toml существует в родительской директории

**Q: Frontend показывает "API недоступен"**

A: 
1. Проверьте статус backend: `curl http://localhost:28000/health`
2. Проверьте контейнеры: `docker-compose ps`
3. Посмотрите логи: `docker-compose logs frontend`
4. Перезапустите: `make restart`

**Q: Ошибка "Database connection failed"**

A:
1. Проверьте что MySQL запущена на хосте
2. Проверьте настройки в `../bd_shared/config.toml`
3. Проверьте подключение из контейнера:
   ```bash
   docker-compose exec backend ping host.docker.internal
   ```

**Q: Как использовать с настоящими AI агентами?**

A:
1. Убедитесь, что `bd_shared/config.toml` настроен для WebReport
2. Экспортируйте OpenAI API ключ в shell: `export OPENAI_API_KEY=ваш-ключ`
3. Запустите или перезапустите стек: `make start` / `make restart`
4. Учтите, что `.env` для Docker Compose генерируется `generate_env.py` из `bd_shared/config.toml`

### Вопросы по данным

**Q: Какие типы отчётов доступны?**

A: В текущей версии:
- Список всех игр
- Список всех команд
- Очки команд по играм
- Статистика отдельной команды
- Топ команд

**Q: Можно ли фильтровать по датам?**

A: Да, используйте запросы типа "игры за период..." (функционал расширяется)

**Q: Как узнать названия команд?**

A: Запросите "покажи все команды"

**Q: Данные обновляются в реальном времени?**

A: Да, данные берутся напрямую из базы данных при каждом запросе
